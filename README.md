Projeto de **Análise Exploratória de Dados (EDA)** desenvolvido a partir de dados de compras de clientes da Instacart.

O objetivo foi analisar o comportamento dos consumidores e identificar padrões relacionados a produtos, pedidos e hábitos de compra.

**Principais atividades:**

- Limpeza e tratamento de dados

- Análise Exploratória de Dados (EDA)

- Identificação de padrões de compra
- Visualização e interpretação dos resultados

**Tecnologias:**  
`Python` `Pandas` `NumPy` `Matplotlib` `Jupyter Notebook`
